# Mystery Island: The Lost Lighthouse
## About the Game

Mystery Island: The Lost Lighthouse is a text-based adventure game
written in Python.

The player explores different locations, collects useful items,
manages energy and tries to reach the Lost Lighthouse.

## Game Features

- Five locations to explore.
- Energy management.
- Collect a rope in the Jungle.
- Collect a lantern in the Cave.
- Cross the Old Bridge using the rope.
- Enter the Lighthouse using the lantern.
- Main menu with start, instructions and quit options.
- Automated tests using Python unittest.

## How to Run the Game

1. Make sure Python 3 is installed on your computer.
2. Open your terminal.
3. Navigate to the Mystery Island project folder.
4. Run the following command:

```bash
python3 mystery_island.py

```markdown
## How to Run Tests
